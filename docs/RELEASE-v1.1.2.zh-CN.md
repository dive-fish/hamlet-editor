# Hamlet Editor 中文增强版 v1.1.2

基于 [Hamlet Editor](https://github.com/zendevio/hamlet-editor) 开发的《暗黑地牢 1》存档编辑器增强版本。项目仓库：[dive-fish/hamlet-editor](https://github.com/dive-fish/hamlet-editor)。

## 重点说明：锁定 5 条黄色怪癖的 MOD

**本人的游戏环境已经安装了可锁定 5 条黄色怪癖（正面怪癖）的 MOD。**

本增强版支持配置 5 条黄色怪癖并全部锁定。如果你也要使用“五黄全部锁定”的配置，请在游戏中自行安装并在对应存档中启用支持该功能的 MOD。**编辑器不附带此 MOD，也不会解除游戏本身的怪癖锁定数量限制。**

这里说明的是本人的使用环境，不代表所有 MOD 组合均已完成兼容性验证。

## v1.1.2 新增：批量添加所有饰品

在“领地 → 饰品仓库”点击“批量添加所有饰品”，设置每种新增 1–99 件。面板显示饰品种类数和新增总件数；应用后点击主界面“保存”。已有饰品保留，重复执行会继续追加。全部饰品指当前游戏目录已加载的饰品目录；未加载目录时无法批量添加。

## 增强功能

- **饰品分类：** 仓库支持分类筛选；批量添加可勾选蓝色（稀有）、先祖、庭院等多个分类，或选择全部。先祖与先祖跛行者饰品归入同一“先祖”分类。
- **棱镜／菱镜怪癖：** 在单人及批量正面怪癖选择器中提供独立筛选，支持“棱镜”“菱镜”“prismatic”搜索。原版 10 种对应 `alien_*` ID。每一种仅允许一名存活英雄持有；同一英雄可拥有多种不同棱镜怪癖，仍遵循正面怪癖数量上限。按游戏定义不可锁定。手动编辑不模拟、推进或重置星空怪掉落顺序。

- **批量怪癖编辑：** 对勾选英雄添加、替换、删除、锁定或解锁怪癖，支持单人及多人操作；应用前可查看修改数量。
- **五黄五红预设：** 按职业默认打法配置，或手动选择近战、远程、治疗、混合打法。黄色怪癖可全部锁定；疾病保留且不占五条红癖的名额。
- **按打法选择红癖：** 近战方案使用远程命中、伤害惩罚；远程方案使用近战伤害、暴击惩罚；治疗方案降低首轮及近战伤害，不降低治疗量。各方案保留不能赌博、不能祈祷、不能去妓院三条城镇限制。请按英雄实际技能选择，远程强盗应手动选择远程方案。
- **战斗技能满级：** 单个英雄或批量升级已解锁的战斗技能，包括未装备技能；保留已装备的技能组合。扎营技能不涉及等级升级。
- **武器、护甲升满：** 同时更新英雄装备等级与独立升级购买记录，修复仅改装备等级导致游戏载入后回退的问题。
- **详细属性：** 怪癖和饰品以主色显示名称、副色显示说明；读取游戏目录中的基础及 DLC 效果，显示数值、触发条件及需要配套装备的饰品套装奖励。
- **远征英雄定位：** 点击远征队伍中的英雄卡片，跳转到英雄页面，滚动并高亮对应条目，同时打开英雄详情。按唯一 ID 区分同名英雄。

## 安装与使用

1. 关闭旧版编辑器，运行 `Hamlet Editor_1.1.2_x64-setup.exe` 更新；也可以解压便携版使用。
2. 在设置中确认游戏目录和存档目录正确，游戏目录用于读取名称及详细属性。
3. 退出游戏并备份存档，打开需要编辑的存档。
4. 应用编辑后，点击主界面“保存”写入存档。

若旧版修改过装备，但进入游戏后仍是初始装备，请在此版本重新应用一次“武器与护甲升满”并保存，补齐装备升级记录。英雄经验等级与装备升级独立，仅提高英雄等级不会自动升级装备。

本版本保留原项目的存档编解码、备份及保存实现。未知 MOD 职业不自动套用原版职业预设；无法识别的属性保留原始标识或字段，供使用者判断。
