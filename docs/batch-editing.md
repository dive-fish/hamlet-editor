# 批量怪癖与装备

在英雄列表勾选一名或多名英雄，上方会出现“批量怪癖与装备”。

- 添加：保留已有怪癖，添加勾选项；超过上限时拒绝整批操作。
- 替换：替换所选颜色的已知怪癖；不选任何怪癖则清空该颜色。
- 移除、锁定、解锁：仅操作英雄已有的勾选项。
- 按打法推荐：配置五个正面、五个负面怪癖。默认按职业分配，也可选近战、远程、治疗、混合打法。未配置职业预设的 MOD 职业会阻止整批应用，需自行选择。
- “添加／替换时锁定黄色怪癖”默认开启；红色怪癖不会因此被锁定。
- “武器与护甲升满”沿用现有编辑器的 0–4 级范围，默认关闭，需主动勾选。

武器和护甲调整会同时更新英雄装备等级与独立的升级购买记录，避免进入游戏后恢复为初始装备。英雄经验等级与装备等级独立；仅修改英雄等级不会自动升级装备。旧版编辑过的英雄可重新应用一次“武器与护甲升满”，然后保存，以补齐升级记录。装备同步仅支持原版职业，缺少升级数据或发现非标准装备层级时不修改。

面板显示每名英雄的增删、锁定数量和目标装备等级。先解决预览中的错误，再应用到内存；最后点击主界面的保存才写入存档，可以使用原有放弃／重置功能撤销尚未保存的编辑。

疾病（含猩红诅咒）及目录中无法识别的 MOD 怪癖不参与分类替换。疾病不占红癖名额；负面和未知怪癖共同检查五项上限。若保留未知项后超限，会拒绝整批应用。已死亡英雄不接受批量编辑。

五红方案均保留 known_cheat、witness、deviant_tastes。近战额外选择 lazy_eye、scattering（远程命中／伤害降低）；远程选择 torn_rotator_cuff、weak_grip（近战伤害／暴击降低）；治疗选择 calm、torn_rotator_cuff（首轮伤害与近战伤害降低，不降低治疗量）；混合打法选择 bad_gambler、faithless（额外城镇限制）。推荐不是无代价配置，请按实际技能选择；远程强盗应主动选择“远程输出”。

怪癖和饰品的添加列表、已装备饰品及庄园饰品卡显示主色名称与副色详细属性。属性从设置中的游戏目录读取基础与 DLC 效果数据，保留触发条件；无法识别的 MOD 效果显示原始标识或字段，不推测数值。描述以纯文本显示。

本修改扩展界面和游戏属性读取，未更换 Rust 存档编解码、备份和保存实现。中英文界面可用，其他编辑器语言使用英文显示本面板。

## 技能满级

勾选英雄后，工具栏提供“批量技能满级”；单英雄的技能标题旁提供“技能满级”。升级已解锁的战斗技能（含未装备项）到5级，保留装备的技能组合。扎营技能无等级，不改动。仅采用原版职业的0–4内部等级；未知MOD职业、异常等级记录、缺少技能目录或已死亡角色跳过并显示提示。操作修改升级记录，仍需点击保存。
